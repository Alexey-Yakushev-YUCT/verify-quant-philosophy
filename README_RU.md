# Количественный смысловой интерпретатор по методологии YUCT (Версия v9)

Репозиторий содержит открытые инструменты для анализа текстов по методологии Единой теории координации (YUCT). Версия v9 использует Динамический координационный фильтр, обеспечивая мгновенный расчет ($O(1)$) и нулевую нагрузку на память.

## 🧠 О проекте v9
Инструмент вычисляет координационную эффективность ($K_{eff} = H(D)/H(I)$) на основе частотного анализа (Шеннон). Включает 3D-сканирование:
1. **Вектор аргументации (Силлогизм):** Типы логики и градиент абстракции.
2. **Семантическая многозначность:** Индекс изолированности и категориальная энтропия.
3. **Эмоциональный спектр:** Скепсис, Догматизм, Angst, Пафос.

## 📊 Психо-онтологическая классификация ($K_{eff}$)
1. **$K_{eff} < 2$ (Хаотический):** Разорванное мышление.
2. **$2 \le K_{eff} < 5$ (Ассоциативно-эмоциональный):** Метафоры, высокий контекст (Ницше).
3. **$5 \le K_{eff} < 10$ (Системно-аналитический):** Структурированная логика (Лейбниц).
4. **$10 \le K_{eff} < 20$ (Концептуально-монументальный):** Сжатые смыслы (Кант).
5. **$K_{eff} \ge 20$ (Формальные мета-системы):** Чистая логика.
