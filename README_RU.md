# Количественная философия YUCT (Раздел «Философский штурм»)

Репозиторий содержит воспроизводимые математические инструменты для верификации экспериментов Единой теории координации (YUCT) на материале философских систем.

## Особенности
* **Без скрытых параметров:** Алгоритм детерминирован, не содержит весов подгонки.
* **Фальсифицируемость:** Любой участник может проверить метрики Канта, Гегеля или собственных статей.

## Быстрый старт
1. Установите библиотеки:
   ```bash
   pip install numpy
   ```
2. Запустите скрипт проверки математического ядра:
   ```bash
   python verify_philosophy.py
   ```
