# Количественный смысловой интерпретатор по методологии YUCT

Репозиторий содержит открытые программные инструменты для верификации, воспроизведения и практического применения экспериментов Единой теории координации (YUCT) на материале философских, научных и авторских текстов.

## 🧠 О проекте

Инструмент реализует алгоритмы частотного анализа и теории информации Шеннона для оценки координационной эффективности мыслительных систем ($K_{eff} = H(D)/H(I)$). Программа детерминирована, не содержит скрытых параметров или ручных весов подгонки. Она позволяет измерить синтаксическую и семантическую плотность текста, переводя гуманитарный аудит на рельсы проверяемой науки.

## 📊 Психо-онтологическая классификация авторов

На основе показателя координационной эффективности ($K_{eff}$), извлекаемого из авторского речевого корпуса, прибор позволяет сканировать архитектуру мышления человека и ранжировать внутренние составляющие личности для когнитивного ассесмента:

1. **Диапазон $K_{eff} < 2$ — Хаотический тип (Кризис координации)**
   * **Суть мышления:** Разорванное, деструктурированное мышление. Отсутствует устойчивый понятийный каркас. Поток сознания без логического стержня.
   * **Профессиональный отбор:** Непригоден для системной, управленческой или аналитической работы. Сигнал о переутомлении или когнитивном кризисе.

2. **Диапазон $2 \le K_{eff} < 5$ — Ассоциативно-эмоциональный тип (Поэты и Полемисты)**
   * **Суть мышления:** Доминирование образного восприятия, высокая контекстуальная избыточность, метафорический шум. Логическая строгость уступает яркости слога и силе эмоций (стиль Ницше, Кьеркегора, публицистика).
   * **Профессиональный отбор:** Идеально подходит для креативных индустрий, искусства, PR, копирайтинга, вдохновения и ведения за собой команд. Не рекомендуется для составления жестких регламентов.

3. **Диапазон $5 \le K_{eff} < 10$ — Системно-аналитический тип (Инженеры и Администраторы)**
   * **Суть мышления:** Развитая, устойчивая логическая структура. Выраженная и дисциплинированная авторская позиция. Умение сжимать информацию, отсекая «воду» (стиль научных монографий, диссертаций, Приложения H2).
   * **Профессиональный отбор:** Идеальные топ-менеджеры, архитекторы корпоративных систем, аналитики высшего звена, авторы государственных программ и законов.

4. **Диапазон $10 \le K_{eff} < 20$ — Концептуально-монументальный тип (Стратеги)**
   * **Суть мышления:** Предельная концентрация смыслов. Аксиоматический базис максимально сжат. Способность координировать гигантские массивы знаний вокруг единого стержня (уровень Канта, Гегеля). Высокая ментальная автономия.
   * **Профессиональный отбор:** Стратегические лидеры, авторы фундаментальных научных прорывов, главные конструкторы и визионеры цивилизационного масштаба.

5. **Диапазон $K_{eff} \ge 20$ — Формальные мета-системы**
   * **Суть мышления:** Чистая логика и математика, полностью очищенная от субъективного и эмоционального шума (уровень канонического ядра YUCT). На малых объемах текста (менее 1000 слов) может указывать на статистическую «аномалию Парменида».

## ⚠️ Превентивная этика (Императивы Appendix Σ)

Объективный отбор и классификация личностей по речевому отпечатку несут в себе фундаментальные социальные риски. Проект руководствуется жесткими этическими императивами:
* **Защита индивидуальности:** Инструмент не является прокрустовым ложем. Низкий или средний $K_{eff}$ не означает ущербность автора — он фиксирует цену (в виде логической избыточности), которую человек платит за свой уникальный художественный стиль. Творческая иррациональность имеет суверенное право на существование.
* **Паритетность и открытость:** Алгоритм детекции открыт и фальсифицируем. Мы категорически против использования подобных метрик в рамках тайного, негласного кадрового или государственного сегрегирования людей. Каждый имеет право лично проверить свой текст и увидеть свой когнитивный профиль.

## 🛠️ Быстрый старт

Для полноценной работы со ссылками и файлами PDF установите необходимые библиотеки:
```bash

```

```bash
python verify_philosophy.py
```
Программа откроет графический интерфейс (GUI), где вы сможете выбрать файл `.txt`, `.pdf` или вставить URL-ссылку на любую интернет-статью. Отчет со сквозными метриками и развернутым психо-онтологической диагнозом сформируется автоматически.
