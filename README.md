# YUCT Quantitative Semantic Interpreter (Version v9)

Open-source tools for analyzing texts using Yakushev Unified Coordination Theory (YUCT). V9 uses a Dynamic Coordination Filter with instant $O(1)$ calculations.

## 🧠 About v9
The tool calculates coordination efficiency ($K_{eff} = H(D)/H(I)$). New 3D scanning includes:
1. **Argumentation Vector (Syllogism):** Logic types and abstraction gradient.
2. **Semantic Multiplicity:** Isolation Index and Categorical Entropy.
3. **Cognitive Affect Spectrum:** Skepticism, Dogmatism, Angst, Pathos.

## 📊 Psycho-Ontological Classification ($K_{eff}$)
1. **$K_{eff} < 2$ (Chaotic):** Fragmented thinking.
2. **$2 \le K_{eff} < 5$ (Associative-Emotional):** High metaphorical context (Nietzsche).
3. **$5 \le K_{eff} < 10$ (Systemic-Analytical):** Structured logic (Leibniz).
4. **$10 \le K_{eff} < 20$ (Conceptual-Monumental):** Condensed meaning (Kant).
5. **$K_{eff} \ge 20$ (Formal Meta-Systems):** Pure logic.
